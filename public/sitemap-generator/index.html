What Is an XML Sitemap?

An XML sitemap is a structured file listing a website's primary URLs for search engine discovery. Established under the Sitemaps.org standard by Google, Yahoo!, and Microsoft, it provides a unified crawling protocol across major search engines.

Each entry includes the page location (<loc>) and optional modification dates (<lastmod>).

Crawl Discovery Aid: A sitemap provides crawling hints—it does not alter search rankings or guarantee indexing.

What URLs Should Be Included in a Sitemap?

Include authoritative, public pages that deliver primary value to search visitors:

  • Canonical URLs: Provide the authoritative version of each page.
  • Important Content Pages: Core landing pages, key services, and valuable articles.
  • Preferred Protocol: Use secure HTTPS URLs matching your preferred domain.
  • Live Pages: Only list pages returning successful 200 OK responses.
  • Indexable Pages: Verify that listed URLs are intended for search visibility.

What URLs Should Not Be Included?

Do not include utility or non-indexable URLs in your sitemap:

  • Query Parameters: Filtered views, sorting parameters, and session IDs.
  • Private Portals: Admin panels, user dashboards, and checkout carts.
  • Redirected URLs: Exclude 301/302 redirects; list only final canonical destinations.
  • Error Pages: Never submit 404 or 500 error pages.
  • Blocked Pages: URLs with noindex tags or disallowed in robots.txt.

Note: Excluding a URL does not prevent indexing. Use noindex to block search engines.

XML Sitemap vs HTML Sitemap

While both map site content, they serve distinct audiences and technical functions:

Audience Search engine bots (Googlebot, Bingbot) Human website visitors
Format Structured XML document Styled HTML navigation page
Location Root directory (/sitemap.xml) Footer link (/sitemap/)
Purpose Crawl discovery & metadata Visitor navigation & accessibility

XML sitemaps aid search crawlers, while HTML sitemaps assist human visitors.

XML Sitemap Format

A standard XML sitemap follows the Sitemaps.org protocol:

<?xml version="1.0" encoding="UTF-8"?> <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"> <url> <loc>https://example.com/</loc> <lastmod>2026-09-01</lastmod> </url> </urlset>

Core Tags Explained

  • <urlset>: Root container referencing the XML namespace.
  • <url>: Container for each individual page record.
  • <loc>: Fully qualified absolute URL of the page.
  • <lastmod>: Last modification date in W3C format (YYYY-MM-DD).

Google has clarified that Googlebot ignores <priority> and <changefreq>. Only accurate <lastmod> timestamps are evaluated.

XML Sitemap Best Practices

Follow established webmaster standards to optimize crawler efficiency:

  • Absolute URLs: Write https://example.com/about/ instead of /about/.
  • Canonical URLs: Match the URL defined in your rel="canonical" tag.
  • Entity Escaping: Convert characters: &amp;, &lt;, and &gt;.
  • Accurate Lastmod: Update <lastmod> only when substantial content changes occur.
  • Server Accessibility: Ensure your sitemap returns 200 OK to search bots.

XML Sitemap Size and URL Limits

Under Sitemaps.org protocol, a single sitemap file is subject to two limits:

  • 50,000 URLs maximum per individual sitemap file.
  • 50 MB maximum uncompressed file size.

Sites exceeding these thresholds must split URLs across multiple files linked by a sitemap index. This tool crawls up to 40 pages within 2 depths, tailored for small websites and blogs.

Sitemap Index Files

A sitemap index organizes multiple sitemap files when a website exceeds 50,000 URLs or separates content types (posts, pages, products):

<?xml version="1.0" encoding="UTF-8"?> <sitemapindex xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"> <sitemap> <loc>https://example.com/post-sitemap.xml</loc> <lastmod>2026-09-01</lastmod> </sitemap> </sitemapindex>

Submitting the index URL to Google Search Console enables search bots to crawl all linked sitemaps automatically.

Do Sitemaps Help Google Index Your Website?

A sitemap helps search engines discover your pages, but submitting a sitemap does not guarantee indexing or ranking. Google independently decides indexing based on:

  • Content Quality: Original, substantive content satisfying search intent.
  • Technical Health: Fast loading speed, mobile usability, and canonical signals.
  • Internal Links: Clear link pathways providing crawl context and authority.

A sitemap ensures discovery; indexing depends on overall site quality.

How to Submit a Sitemap to Google

Publish your sitemap to your web server and submit it using two standard methods:

Submitting in Google Search Console

  1. Open Google Search Console and select your verified domain.
  2. Navigate to Indexing > Sitemaps in the sidebar.
  3. Enter sitemap.xml under Add a new sitemap and click Submit.

Referencing in Robots.txt

Sitemap: https://example.com/sitemap.xml

Sitemap and Robots.txt

While both files guide search bots, they perform contrasting functions:

  • robots.txt: Specifies crawl permissions and restricts bot access.
  • sitemap.xml: Highlights the preferred public pages you want discovered.

Key Difference: A sitemap cannot override robots.txt. Disallowed pages will not be crawled even if listed in your sitemap.

Common XML Sitemap Problems

Technical audits often identify recurring sitemap configuration errors:

  • Unescaped Ampersands: Raw & characters break XML parsing; use &amp;.
  • Relative URLs: Omission of protocol and domain violates Sitemaps.org schema.
  • Mixed Protocols: Listing HTTP URLs on HTTPS websites forces redirects.
  • Broken 404 Links: Including dead URLs wastes search bot crawl resources.
  • Blocked Sitemap: Adding disallow directives in robots.txt for sitemaps.

Why Is Google Not Indexing My URL After I Submitted a Sitemap?

A sitemap assists discovery, but Google decides indexing based on several factors:

  • Crawl Queue: Google schedules crawling by domain authority and server capacity.
  • Discovered - Not Indexed: The URL was found but not yet crawled.
  • Crawled - Not Indexed: Evaluated but excluded due to thin content or duplication.
  • Canonical Choice: Google selected a different URL as canonical.
  • Internal Links: The page lacks sufficient contextual internal links.

When Should You Generate a New Sitemap?

Update your sitemap when your site structure undergoes meaningful changes:

  • New Website Launch: Submits initial indexable pages to search engines.
  • Adding Sections or Products: Expands crawler coverage to newly published content.
  • Site Migrations & Redesigns: Crucial after URL restructures or migrations.
  • Content Pruning: Removes retired pages and updates redirect targets.

XML Sitemap vs Site Navigation

A sitemap supports URL discovery, but it never replaces internal links. Search engines rely on internal links to understand topical hierarchy and distribute authority.

Pages linked from primary navigation are crawled frequently and indexed reliably. Optimal technical SEO integrates strong internal linking with a clean XML sitemap.
